# Was ist das?
Repo zum Sammeln von Strategien und Lineups für unser team.

# Wie füge ich hier was hinzu?
Nach Freischaltung als Collaborator (an Mirko wenden mit Accountlink) mit einem beliebigen Git-Client. Am einfachsten direkt [Visual Studio Code](https://code.visualstudio.com/) benutzen, damit kann man auch gleich die .md-files einfach bearbeiten und da ist git integriert.

## Strategie-Bilder
Die Bilder für Defaults und Executes mit Util und Positionen der Spieler werden über [CS2 Strats](https://cs2strats.gg/) generiert. Kann nicht sehr viel, reicht aber für unsere Zwecke und ist einfach zu bedienen und kostenlos, braucht keinen Account.
